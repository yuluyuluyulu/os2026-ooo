# Lab3 启动与截图步骤

本次五组实际运行截图已整理进 `report/images` 并插入报告；GDB 使用小组提供的完整手动操作截图，自动日志版截图及其重复图未纳入。以下步骤保留供复现或后续重新截图使用。

代码位于 Windows `D:\cc-dp\os\code`，WSL 路径为 `/mnt/d/cc-dp/os/code`。下面除第一条外，所有命令都在 **WSL Ubuntu 终端**输入。命令逐段执行，每次等待回到 shell 后再继续。

截图保存到 `D:\cc-dp\os\report\images`，也可以直接发到聊天里，我再按对应编号整理。截图应保留命令及结果；终端建议宽约 120 列、字体 14～16，便于完整显示 PASS 行。

## 0. 进入 WSL

打开 Windows Terminal 或 PowerShell：

```powershell
wsl -d Ubuntu-22.04
```

进入 Ubuntu 后：

```bash
cd /mnt/d/cc-dp/os/code
```

以下构建、运行和调试目标都不包含 Git 提交或上传。Lab3 第一版使用独立的 `codex/lab3` 分支；旧 Lab2 文件已本地备份在 `.local-backup`，该目录被 Git 忽略，前两次实验也保留在各自分支和 Git 历史中。

## 2. 默认启动与定时关机截图：02-timer-shutdown.png

```bash
make qemu
```

约十余秒后内核会自动关机，终端回到 shell。截取以下内容，尽量在同一屏中保留 10 行 `100 ticks` 和结尾：

```text
check_alloc_page() succeeded!
...
++ setup timer interrupts
100 ticks
...（共十行）
Timer shutdown: 1000 ticks, 10 reports
```

截图时不要输入上面的示意文本，截实际终端即可。默认启动不执行独立自检。若暂时只见 OpenSBI，等待一会儿；正常情况下应继续出现内核信息。中途需要退出 QEMU 时按 `Ctrl+A`，松开，再按 `X`，但本张截图应等待自动关机。

### 可选：手动双终端调试

如果想亲自操作，终端 A 在 WSL 中运行：

```bash
cd /mnt/d/cc-dp/os/code
make clean
make DEFS=-DLAB3_SELFTEST
make debug
```

此时 QEMU 在启动前暂停，终端没有新的内核输出是正常的。终端 B 也进入 WSL：

```bash
cd /mnt/d/cc-dp/os/code
make gdb
```

之后以下 GDB 命令 **每条单独回车**：

```gdb
set pagination off
b trap
c
p sizeof(struct trapframe)
p/x tf->cause
p/x tf->status
p/x tf->gpr.sp
p/x tf->epc
x/2hx tf->epc
set $saved_epc = tf->epc
set $frame = tf
disable 1
thbreak __trapret
c
p/x $frame->epc
p $frame->epc - $saved_epc
set $return_sp = $frame->gpr.sp
thbreak *$frame->epc
c
p/x $pc
p/x $sp
p/x $sscratch
p $sp == $return_sp
x/i $pc
```

两次差值/比较的预期结果分别是 2 和 1。不要对照另一种宏构建写死地址；始终从本次 `tf->epc` 取值。优化编译可能使 `finish` 停点不符合预期，所以这里直接停在汇编边界。

结束时在 GDB 输入：

```gdb
detach
quit
```

终端 A 等待自动关机，或按 `Ctrl+A`，松开，再按 `X`。若提示 1234 端口被占用，先退出之前自己启动的 QEMU 调试会话，再启动新的 `make debug`。

## 6. 恢复默认构建

完成所有截图后执行：

```bash
make clean
make
```

这是因为 Makefile 不会自动识别 `DEFS` 参数变化。独立自检和 GDB 目标会自行 clean，但之后手动运行默认 `make qemu` 前应先执行上面两条，避免继续运行上一次带自检宏的镜像。

需要重新验证全部结果时：

```bash
make grade
make selftest
make shutdown-test
```

以上命令依次验证课程评分、自检和默认关机；最后一项会留下默认构建。不要同时在两个终端运行会 clean/重建的目标。
